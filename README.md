# Практичне завдання: ToDo List

## Опис проєкту

У межах практичного завдання було створено базовий frontend-вебдодаток "ToDo List".
Додаток дозволяє додавати нові завдання, відмічати їх як виконані та видаляти зі списку.

## Використані технології

- HTML
- CSS
- JavaScript
- localStorage браузера

## Функціонал

1. Додавання завдання через форму.
2. Відмічання завдання як виконаного за допомогою checkbox.
3. Видалення завдання зі списку.
4. Збереження завдань у localStorage.
5. Автоматичне відображення збережених завдань після перезавантаження сторінки.

## Як запустити

1. Завантажити файли проєкту.
2. Відкрити файл `index.html` у браузері.
3. Почати додавати завдання.

## Аналіз використання ChatGPT

Для виконання практичного завдання ChatGPT було використано як інструмент генерації та пояснення коду.
Спочатку було сформульовано запит на створення базового ToDo List із трьома основними функціями: додавання, виконання та видалення завдань.
Після отримання коду було проаналізовано його структуру та розділено проєкт на три файли: `index.html`, `style.css` і `script.js`.

HTML-файл відповідає за структуру сторінки.
CSS-файл використовується для оформлення інтерфейсу.
JavaScript-файл містить основну логіку роботи додатку: обробку форми, створення завдань, зміну статусу виконання, видалення та збереження даних у localStorage.

Отриманий код було адаптовано під вимоги завдання: залишено тільки frontend-частину, додано збереження у localStorage та зроблено простий зрозумілий інтерфейс.
